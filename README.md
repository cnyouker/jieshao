## 📌 项目简介

“循古排盘”是一个致力于还原传统经典命理逻辑的高精度排盘引擎。在现代泛滥的排盘工具中，本项目摒弃了部分未经古籍验证的“现代修正”（如盲目滥用真太阳时），而是严格遵循《三命通会》、《渊海子平》及《卜筮正宗》等古籍的底层算法逻辑，致力于为专业易学研究者和开发者提供最纯粹、最可靠的底层数据与排盘接口。

## ✨ 核心特性 (Core Features)

*   **⏱️ 严谨的古法历法引擎**
    *   **非真太阳时逻辑：** 传统的古代历法与阴阳五行建构在标准的节气与干支体系之上。本算法摒弃了现代真太阳时对古法干支的机械切割，最大程度还原古人定局的时辰刻度。
    *   **高精度节气交接：** 内置精准天文星历算法（支持公农历无缝转换），确保节气交接点精确到分，八字干支排布毫厘不差。
*   ** 精准的六爻起卦架构**
    *   支持手动摇卦、时间起卦等多种经典排盘模式。
    *   自动精准安放世应、六亲、六神，并严密计算旬空、伏神与日月建的生克冲合关系，为断卦提供最清晰的数据视图。
*   **🔗 「同气相求」—— 四柱级同生人匹配引擎 (New)**
    *   **多档递进寻缘：** 突破传统仅按公历“寻找同年同月同日出生的人”的低精度检索。系统支持**同缘**（公历同年月日）、**同盘**（四柱干支完全相同、性别不同导致大运逆行）与**同命**（四柱干支与性别完全相同，真正的红尘镜像）的三档递进精准匹配。
    *   **流年履历盲盒博弈：** 坚持**零自由文本输入**原则，彻底免疫任何风控风险与敏感言论。基于“学、姻、财、身”四大红尘缘分进行纯结构化标签录入，通过“我先亮牌，方可单向解锁查看对方流年”的博弈机制，实现完全脱敏的流年吉凶走向与大运分流验证。
    *   **红尘共鸣度量化：** 基于双方已解锁流年标签的吉凶极性（Polarity）同向度，量化计算“红尘共鸣指数”，并支持前端一键 Canvas 渲染导出「双生镜像/一体两面/南辕北辙」古风海报，自带高粘性社交裂变属性。
*   **🚀 轻量级与开发者友好**
    *   无冗余的商业化弹窗与广告代码，纯粹的逻辑计算引擎。
    *   数据结构高度标准化（JSON 格式化输出友好），方便快速集成到各类 Web 站、移动端应用或自动化分析流程中。
    *   **极致的 SQLite 并发优化：** 「同气相求」模块完全基于结构化外键索引（INTEGER），不存储任何大 TEXT。在 SQLAlchemy 连接层挂载 WAL 模式、同步策略优化及高并发忙等待（Busy Timeout），保证高频社交状态提交下不产生数据库写锁阻塞。

## 🛠️ 技术哲学

命理学的基础是严密的天文学与数学模型。本项目旨在用现代代码重构千年前的智慧运算，以极简的代码架构，实现最深度的易学推演。不造神、不玄虚，只做最硬核的规则引擎。

## 📈 未来进阶：大数据断语验证

随着「同气相求」模块中大量真实用户流年履历数据的积累，项目未来将开辟**“宏观共盘案例看板”**。由于标签全部实现了结构化存储（`tongqi_tags`），系统天然支持无监督统计（如：“统计显示，当该八字遭遇特定流年‘伤官见官’时，有 78% 的同生人反馈了真实的职场变动”），以此打造全网独一无二的硬核玄学学术大数据，用真实红尘案例反哺并验证传统命理断语的应验率。
